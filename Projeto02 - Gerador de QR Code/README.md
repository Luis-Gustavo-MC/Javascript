# 📱 Gerador de QR Code

Um projeto prático desenvolvido em **JavaScript** que permite converter links ou textos em QR Codes de forma instantânea. Ideal para facilitar o compartilhamento de informações de maneira rápida e visual.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando o trio fundamental do desenvolvimento web, sem a necessidade de frameworks complexos:

* **HTML5**: Estruturação semântica da interface.
* **CSS3**: Estilização moderna e responsiva.
* **JavaScript (ES6+)**: Manipulação do DOM e integração com API.
* **QR Server API**: API externa utilizada para a geração dinâmica das imagens dos códigos.

## 🛠️ Funcionalidades

* **Geração Instantânea**: Cria um QR Code assim que o usuário insere a URL ou texto e clica no botão.
* **Limpeza de Campo**: Detecta quando o campo está vazio para evitar requisições desnecessárias.
* **Interface Responsiva**: Design que se adapta a diferentes tamanhos de tela (desktop e mobile).
* **Feedback Visual**: O QR Code aparece com uma transição suave após o carregamento.

## 📸 Demonstração

Para utilizar o projeto, basta seguir estes passos:

1. Digite o link ou texto no campo de entrada.
2. Pressione o botão **"Gerar QR Code"**.

## 📂 Como executar o projeto

Como este é um projeto baseado em tecnologias front-end puras, você não precisa instalar dependências pesadas.

1. Clone o repositório:
```bash
git clone https://github.com/Luis-Gustavo-MC/Javascript.git
```

2. Navegue até a pasta do projeto:
```bash
cd "Projeto02 - Gerador de QR Code"

```
3. Abra o arquivo `index.html` no seu navegador de preferência.
